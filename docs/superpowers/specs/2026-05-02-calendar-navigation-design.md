# Спецификация: Навигация календаря (Месяц/Год и Стрелки)

Добавление возможности переключения месяцев и лет в календаре с использованием выпадающих списков и кнопок навигации.

## 1. Обзор
Пользователю необходимо быстро перемещаться по календарю. Для этого будут реализованы:
- Выпадающий список выбора месяца.
- Выпадающий список выбора года (динамический диапазон ±10 лет).
- Кнопки "Вперед" и "Назад" для пошагового переключения месяцев.

## 2. Архитектура и Технологии
- **Библиотека Dropdown:** `@radix-ui/react-select` (Radix UI Select).
- **Иконки:** `lucide-react`.
- **Архитектура:** Feature-Sliced Design (FSD).
- **Стейт-менеджмент:** Redux Toolkit.

## 3. Изменения в состоянии (Redux)
В `src/entities/calendar/model/slice.ts` (uiSlice) необходимо добавить:
- `viewDate: string` (ISO string) — дата, определяющая текущий отображаемый месяц и год. По умолчанию — текущая дата.
- Редьюсеры:
    - `nextMonth()`: увеличивает `viewDate` на один месяц.
    - `prevMonth()`: уменьшает `viewDate` на один месяц.
    - `setViewDate(date: string)`: устанавливает произвольную дату просмотра.

## 4. Компоненты (UI)

### 4.1. Обновление `CalendarGrid`
- Выделение логики шапки в отдельный внутренний компонент или секцию.
- Замена статического заголовка `<h2>` на интерактивную панель управления.

### 4.2. Панель навигации (Layout C: Split)
- **Левая часть:**
    - `MonthSelect`: Компонент на базе Radix UI Select. Отображает названия месяцев (Январь - Декабрь).
    - `YearSelect`: Компонент на базе Radix UI Select. Отображает года (текущий ± 10 лет).
- **Правая часть:**
    - Кнопки `<` и `>` с иконками `ChevronLeft` и `ChevronRight` из `lucide-react`.

## 5. Взаимодействие
1. При клике на стрелки вызываются экшены `nextMonth` / `prevMonth`.
2. При выборе значения в дропдауне вызывается `setViewDate` с новой датой (первое число выбранного месяца/года).
3. `CalendarGrid` отображает дни на основе `viewDate` из стора.

## 6. Тестирование
- Проверить, что при переходе с 31 января "вперед" корректно отображается февраль.
- Убедиться, что изменение года в дропдауне мгновенно обновляет сетку календаря.
- Проверить доступность (управление дропдаунами с клавиатуры).

1. Установка зависимостей (`@radix-ui/react-select`, `lucide-react`, `class-variance-authority`, `clsx`, `tailwind-merge` — стандартный набор для компонентов типа shadcn).
2. Обновление Redux-слайса (`uiSlice`).
3. Создание базовых UI-компонентов Select (в стиле shadcn/ui).
4. Интеграция компонентов в `CalendarGrid`.
5. Стилизация (CSS Modules).
