# Спецификация: Безопасность (RLS) и Ролевая Модель

**Дата:** 2026-05-03
**Статус:** Draft
**Тема:** Внедрение Row Level Security (RLS) в Supabase для изоляции данных гильдий и управления правами доступа.

## 1. Цели
- Обеспечить полную изоляцию данных: пользователи видят события только тех гильдий, в которых они состоят.
- Реализовать ролевую модель: Owner, Admin, Member.
- Разграничить права на редактирование календаря (только Owner и Admin).

## 2. Ролевая модель
| Роль | Просмотр событий | Создание/Редактирование | Управление гильдией |
| :--- | :---: | :---: | :---: |
| **OWNER** | ✅ | ✅ | ✅ |
| **ADMIN** | ✅ | ✅ | ❌ |
| **MEMBER** | ✅ | ❌ | ❌ |

## 3. Правила Row Level Security (RLS)

### Таблица `guilds`
- **SELECT**: Пользователь является участником гильдии (`user_id` в `guild_members`).
- **INSERT**: Авторизованный пользователь (`auth.uid()` не null).
- **UPDATE/DELETE**: Пользователь имеет роль `OWNER` в этой гильдии.

### Таблица `guild_members`
- **SELECT**: Пользователь является участником этой гильдии.
- **INSERT**: Только `OWNER` или `ADMIN` гильдии может приглашать/добавлять (или система при создании гильдии).
- **UPDATE/DELETE**: Только `OWNER` (для смены ролей или удаления участников).

### Таблица `events`
- **SELECT**: Пользователь является участником гильдии, к которой относится событие.
- **INSERT/UPDATE/DELETE**: Пользователь имеет роль `OWNER` или `ADMIN` в этой гильдии.

## 4. SQL функции для упрощения политик
Для эффективной проверки прав будут созданы вспомогательные функции:
- `is_guild_member(guild_id)`: Возвращает true, если текущий пользователь состоит в гильдии.
- `has_guild_role(guild_id, required_roles[])`: Проверяет, совпадает ли роль пользователя с одной из требуемых.

## 5. Этапы реализации
1. **SQL Migration**: Написание и выполнение скрипта для включения RLS и создания политик.
2. **UI Updates**: Скрытие кнопок "Создать событие" или "Настройки гильдии" для пользователей с ролью `MEMBER`.
3. **Error Handling**: Обработка ошибок доступа (403 Forbidden) на уровне API.

## 6. Деплой (ОТЛОЖЕНО)
