# Руководство по использованию CSS-единиц (CSS Units Style Guide)

В этом документе описаны правила и соглашения по использованию единиц измерения `px` (пикселей) и `rem` в кодовой базе проекта Guild Master. Эти правила обеспечивают доступность (accessibility), адаптивность и простоту поддержки интерфейса.

---

## 📐 Единица измерения REM

Относительная единица `rem` (root em) рассчитывается на основе размера шрифта корневого элемента (`html`). При стандартных настройках браузера `1rem = 16px`.

### Области применения:
1.  **Типографика (`font-size`)**:
    *   Все размеры шрифтов для текстовых элементов должны задаваться исключительно в `rem`. Это гарантирует корректное масштабирование текста при изменении настроек масштаба или размера шрифта пользователем в браузере.
    *   *Исключение:* Мелкие фиксированные графические элементы (например, инициалы внутри круглого `UserAvatar`), где размер текста жестко привязан к размерам контейнера в пикселях.
2.  **Внутренние и внешние отступы макета (`padding`, `margin`, `gap`)**:
    *   Для крупных блоков разметки (страницы, карточки, секции, формы) следует использовать `rem`. Это позволяет отступам масштабироваться пропорционально тексту при масштабировании интерфейса.
3.  **Крупные размеры и переменные**:
    *   Основные размеры глобального макета, такие как высота шапки (`--header-height`) или ширина боковой панели (`--rail-width`), должны задаваться в `rem` (например, `3rem` вместо `48px`), чтобы формулы расчетов на их основе (внутри `calc()`) оставались консистентными.

---

## 📏 Единица измерения PX

Пиксель `px` является абсолютной единицей измерения и используется там, где размеры элементов не должны зависеть от масштаба шрифта пользователя.

### Области применения:
1.  **Границы (`border`, `border-width`, `outline`)**:
    *   Всегда задаются в `px` (например, `1px solid var(--glass-border)`). Это гарантирует четкость линий на экранах с любым разрешением (включая High-DPI/Retina дисплеи) без размытия, которое может возникнуть при округлении относительных величин.
2.  **Эффекты и тени (`box-shadow`, `text-shadow`, `filter: blur()`, `backdrop-filter: blur()`)**:
    *   Параметры сдвига, размытия и растяжения теней должны указываться в `px` для достижения точного визуального эффекта.
3.  **Компоненты с жестко фиксированными размерами**:
    *   Элементы интерфейса с фиксированными габаритами: чекбоксы, переключатели (switch), мелкие иконки, аватары пользователей, а также закругления углов (`border-radius`), имеющие строгие ограничения по геометрии макета.
4.  **Медиа-запросы (`@media` breakpoints)**:
    *   Точки перелома адаптивной верстки (например, `max-width: 768px`, `max-width: 1024px`) всегда указываются в `px`.

## 🚫 Запрещенные практики (Best Practices / Anti-patterns)

1.  **Смешение единиц в рамках одного CSS-свойства**:
    *   *Неправильно:* `padding: 12px 1rem 8px 2rem;`
    *   *Правильно:* `padding: 0.75rem 1rem 0.5rem 2rem;`
2.  **Смешение единиц внутри функции `calc()`**:
    *   Выражения в `calc()` должны быть однородными или использовать переменные, приведенные к общей единице измерения.
    *   *Неправильно:* `padding-top: calc(var(--header-height) + 10px);` (если `--header-height` задана в `px`, а остальная верстка в `rem`).
    *   *Правильно:* `padding-top: calc(var(--header-height) + 0.625rem);` (где `--header-height` определена в `rem`).
